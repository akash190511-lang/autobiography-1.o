# AKASH — The Journey So Far

A standalone HTML/CSS/JS personal journey website.

## Open it
Double-click `index.html` to preview it in Chrome/Edge.

## Add your real photos
Put your images inside the `assets` folder and replace the placeholder blocks in `index.html`.
The current version intentionally uses placeholders because your complete photo/certificate set was not included in this download.

## Publish for free
This is plain HTML/CSS/JS, so it works with GitHub Pages and other static hosting.

Suggested structure:
- index.html
- style.css
- script.js
- assets/

## Current sections
- Hero / introduction
- Timeline
- Then → Now memory wall
- Achievements / certificates
- Current focus
- Future / next chapter
